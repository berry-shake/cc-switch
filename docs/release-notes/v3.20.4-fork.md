# v3.20.4 fork 合并说明

本分支合并上游正式 tag `v3.20.4`，保留已有 OMP、Codex 用量统计和精简界面定制。

## 数据库兼容

上游 v19 为 MCP/Skills 增加 `enabled_mcode`，本分支已发布的 v19 则增加了 `enabled_omp`。
本次使用 schema v20 统一两种布局：按列存在性补齐缺失的开关列，已有开关值、元数据和会话同步游标不变。
从本分支 v19、上游 v19，以及已经同时具有两列的 v19 升级均有回归测试；重复启动不会重置开关。

升级前应保存一致性数据库快照和旧版应用。回滚到本分支 v3.20.3 时，必须配套恢复升级前数据库，不能让旧版直接打开 schema v20。
上游正常启动时的定价修复、日志保留策略仍然生效；本次合并不主动执行 Codex 历史安全重建。

## 保留的定制

- OMP 与 MiniMax Code 独立管理供应商、MCP、Skills、提示词和会话。
- Codex 原始 Credits 口径、Astra Fast 倍率、缓存写入统计与安全重建审计。
- 原有六格容量面板和独立预测区，不恢复模型/每日 Credits 明细。
- 上游输出速度仅显示在既有请求日志/详情的输出指标中，不替代缓存写入或缓存读取指标。
