# v3.20.4 fork: Fast accounting correction (2026-09-24)

This fork-only rebuild keeps the existing version and UI. No database schema
upgrade, automatic history rebuild, or model/daily detail panel is introduced.

## Changes

- Add GPT-6 Sol and Luna Standard API prices to the built-in price table.
- Apply the documented 2.5x subscription Fast multiplier to both new models in
  the Codex JSONL importer and token-based analytics estimate. Accept both
  `fast` and `priority` labels in analytics.
- Keep cache-write token counts and bill them at the ordinary input rate in
  recognized Codex models' subscription quota estimates. These tokens are split
  out of uncached input, so no separate write charge means no API write premium,
  not free input. Shared API prices and the generic API cost calculator remain
  unchanged.
- Continue using official personal Credits directly. Do not apply Fast a second
  time or replace missing official Credits with locally estimated costs.
- Keep OMP reported costs authoritative when importing OMP logs; they may already
  include a service-tier premium and must not be multiplied again.

## Verification and history boundary

Regression tests cover new-model prices, Fast/Standard and effort suffixes,
cache-write token preservation, API price isolation, duplicate-import prevention,
and unmodified Astra/Sol/Luna official Credits. Full frontend and Rust suites are
part of delivery verification.

New imports and token-based analytics use the corrected rules. Existing persisted
session costs and archived rollups are not silently repriced. The existing manual
history maintenance workflow remains explicit; missing source logs cannot be
reconstructed by changing a multiplier.

Before installation, back up the previous application, DMG and SQLite database.
Restore the paired application/database backup if rolling back.
